# Contributing to HandControlPro
# راهنمای مشارکت در HandControlPro

Thank you for your interest in contributing to HandControlPro!

از علاقه شما به مشارکت در توسعه HandControlPro سپاسگزاریم!

We welcome developers, testers, and users who want to help improve this project.

از توسعه‌دهندگان، آزمایش‌کنندگان و کاربران علاقه‌مند به بهبود این پروژه استقبال می‌کنیم.

---

## 1. How to Contribute | نحوه مشارکت

You can contribute to HandControlPro in several ways:

شما می‌توانید از روش‌های مختلف در توسعه HandControlPro مشارکت کنید:

- Report bugs and issues.  
  گزارش خطاها و مشکلات نرم‌افزار.
- Suggest new features.  
  پیشنهاد قابلیت‌های جدید.
- Improve existing features.  
  بهبود قابلیت‌های موجود.
- Fix bugs and optimize the code.  
  رفع اشکالات و بهینه‌سازی کد.
- Improve documentation and translations.  
  بهبود مستندات و ترجمه‌ها.

---

## 2. Reporting Bugs | گزارش خطا

Before reporting a bug:

قبل از گزارش یک خطا:

1. Check whether the issue has already been reported.  
   بررسی کنید که مشکل قبلاً گزارش نشده باشد.
2. Make sure you are using the latest version.  
   مطمئن شوید از آخرین نسخه استفاده می‌کنید.
3. Provide clear steps to reproduce the issue.  
   مراحل بازتولید مشکل را به‌صورت واضح توضیح دهید.
4. Include error messages or screenshots if possible.  
   در صورت امکان، تصویر یا متن خطا را ارسال کنید.

---

## 3. Suggesting Features | پیشنهاد قابلیت جدید

Feature requests are always welcome!

از پیشنهاد قابلیت‌های جدید استقبال می‌کنیم!

Please explain:

لطفاً موارد زیر را توضیح دهید:

- What the feature does.  
  قابلیت پیشنهادی چه کاری انجام می‌دهد؟
- Why it would be useful.  
  چرا این قابلیت مفید است؟
- How you think it should work.  
  به نظر شما این قابلیت چگونه باید کار کند؟

---

## 4. Development Guidelines | قوانین توسعه

Please follow these guidelines when contributing code:

هنگام مشارکت در توسعه کد، لطفاً این موارد را رعایت کنید:

- Write clean and readable Python code.  
  کد پایتون تمیز و خوانا بنویسید.
- Keep the existing project structure.  
  ساختار فعلی پروژه را حفظ کنید.
- Use meaningful variable and function names.  
  از نام‌های معنادار برای متغیرها و توابع استفاده کنید.
- Avoid unnecessary dependencies.  
  از وابستگی‌های غیرضروری خودداری کنید.
- Test your changes before submitting them.  
  قبل از ارسال تغییرات، آن‌ها را آزمایش کنید.

---

## 5. Pull Requests | ارسال تغییرات

To submit your changes:

برای ارسال تغییرات خود:

1. Fork the repository.  
   یک Fork از مخزن ایجاد کنید.
2. Create a new branch.  
   یک شاخه جدید ایجاد کنید.
3. Make your changes.  
   تغییرات خود را اعمال کنید.
4. Test your changes.  
   تغییرات را آزمایش کنید.
5. Submit a Pull Request with a clear description.  
   یک Pull Request همراه با توضیحات واضح ارسال کنید.

---

## 6. Code of Conduct | اصول رفتاری

- Be respectful and friendly.  
  محترمانه و دوستانه رفتار کنید.
- Respect other contributors.  
  به سایر مشارکت‌کنندگان احترام بگذارید.
- Provide constructive feedback.  
  بازخورد سازنده ارائه دهید.
- Welcome beginners and experienced developers alike.  
  از تازه‌کاران و توسعه‌دهندگان باتجربه به یک اندازه استقبال کنید.
